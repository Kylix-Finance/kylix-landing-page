title: "Privacy"
description: "What Kylix does with the email address you submit on the waitlist."
---

The only personal data this site asks for is an email address, on the waitlist form.

The operator of that list is Kylix Labs LLC, registered in Saint Vincent and the Grenadines.

## What is collected

The form sends your email address to this site's server. The server passes it to Brevo, which stores the list. The form does not ask for a name, a wallet address or a payment.

## Why

The address is used to say when a testnet or a mainnet date exists, and for occasional notes about the protocol. The list is not sold.

## How long it is kept

The address stays on the list until you ask for it to be removed. Write to [info@kylix.finance](mailto:info@kylix.finance) from that address and it will be deleted from the list this site controls.

## What this site does not do

These pages do not set their own analytics cookies. If that changes, this note changes first.
